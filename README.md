# Sentiment Classification and Summarization of E-Commerce Product Reviews

## Abstract

This project focuses on analyzing e-commerce product reviews using Natural Language Processing.

The system performs two main tasks:

- Sentiment Classification
- Review Summarization

For sentiment classification, models such as Logistic Regression, SVM, and BERT are used to classify reviews as positive or negative.

For summarization, BART is used to generate short summaries of customer reviews.

## Dataset

The project uses an e-commerce product review dataset.

Ratings are converted into sentiment labels:

- 1–2 stars: Negative
- 4–5 stars: Positive
- 3 stars: Removed

## Models Used

- Logistic Regression
- Support Vector Machine
- BERT
- BART

## Technologies

- Python
- Natural Language Processing
- BERT
- BART
- Hugging Face Transformers
- Scikit-learn
- Pandas
- Jupyter Notebook

## Objective

The goal of this project is to automatically understand customer sentiment and summarize product reviews using NLP techniques.
